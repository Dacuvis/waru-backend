# Public

Folder ini digunakan sebagai tempat penyimpanan asset publik yang dapat diakses secara statis.

---

## Kegunaan

- Menyimpan file gambar (`.jpg`, `.png`, `.webp`, dll)
- Menyimpan file statis lainnya yang perlu diakses dari luar

---

## Catatan

- File di folder ini bersifat publik dan dapat diakses langsung via URL.
- Jangan simpan file sensitif (credentials, config, dll) di folder ini.
